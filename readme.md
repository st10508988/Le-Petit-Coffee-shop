# Le Petite Coffee Website

## 1. Project Overview

Le Petite Coffee is a small coffee shop located in Oakdene, Johannesburg South. The purpose of this website is to create a useful and visually appealing online presence for the coffee shop.

The website provides customers with information about the organisation, its menu, contact details, and a way to make enquiries.

## 2. Website Objectives

The main objectives of the website are to:

- Improve Le Petite Coffee's online presence.
- Provide information about the café.
- Display the products and menu.
- Allow customers to make enquiries.
- Provide contact and location information.
- Make the website accessible on desktop and mobile devices.

## 3. Website Pages

The website consists of five main pages:

1. **Home (`index.html`)**
   - Introduction to Le Petite Coffee.
   - Hero section.
   - Featured products.
   - Call-to-action buttons.

2. **About Us (`about.html`)**
   - Organisation background.
   - Mission statement.
   - Vision statement.
   - Target audience.

3. **Products/Menu (`products.html`)**
   - Coffee.
   - Tea.
   - Hot chocolate.
   - Pastries.
   - Sandwiches.
   - Light meals.

4. **Enquiry (`enquiry.html`)**
   - Customer enquiry form.
   - Name, email and phone fields.
   - Enquiry type.
   - Message section.

5. **Contact Us (`contact.html`)**
   - Contact information.
   - Location.
   - Opening hours.
   - Social media links.
   - Contact form.
   - Google Maps location.

## 4. Technologies Used

The website was developed using:

- HTML5 – used to create the structure and content of the website.
- CSS3 – used to style the website and create the visual design.
- JavaScript – used to provide interactive functionality and form validation.

## 5. CSS Styling and Layout

CSS is a key part of the website's design and helps create a welcoming coffee-shop aesthetic. The styling is used to control layout, spacing, typography, colour, and responsiveness across all pages.

The CSS includes:

- A warm coffee-inspired colour palette using brown, cream, white, and dark green tones.
- Consistent spacing and alignment for sections such as the hero banner, navigation, menu cards, and footer.
- Typography styling for headings and body text to improve readability and brand presentation.
- Button styles and form styling for a clean and professional user experience.
- Responsive CSS rules using media queries to adapt the layout for tablets and mobile devices.
- Hover effects and visual states that improve interactivity and usability.

This ensures the website remains visually appealing, easy to navigate, and accessible on different screen sizes.

## 6. Design and Branding

The website uses a warm coffee-shop inspired design based on the organisation's proposal.

The main colours are:

- Brown
- Cream
- White
- Dark green

Aptos Display is used for headings and Sanskrit Text is used for body text.

The website uses clear navigation, call-to-action buttons, images, and a responsive layout to improve the user experience.

## 7. Target Audience

The target audience includes:

- Students
- Working professionals
- Families
- Visitors
- Local customers
- People looking for good coffee, food, and a cosy space to connect or work.
